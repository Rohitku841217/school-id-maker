SCHOOL ID CARD MAKER — HINDI SETUP

1. ZIP file extract karein.
2. School-ID-Software folder kholen.
3. index.html ko Chrome, Edge ya kisi modern browser me kholen.
4. School name/address/session set karein.
5. Student form bharein, photo select karein, aur "कार्ड जोड़ें" dabayein.
6. Excel/CSV import ke liye pehli row me ye columns rakhein:
   Name, Class, Roll, DOB, Father, Mobile
7. Sab cards print/PDF ke liye "सभी कार्ड प्रिंट / PDF" dabayein.
   Print dialog me "Save as PDF" select karein.
8. Student data usi browser ke local storage me save hota hai.
   Browser data clear karne par data mit sakta hai; CSV export se backup rakhein.

NOTES:
- Excel import library CDN se load hoti hai, isliye import karte waqt internet chahiye.
- Photo aur logo browser ke local storage me data URL ke roop me store hote hain.
- Ye starter website hai; isme server login, cloud sync, multi-user access ya database nahi hai.
